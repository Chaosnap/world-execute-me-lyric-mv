# 還想要的剪影

第四版用的是八張三色剪影:`f_bust`(正面胸像,無臉)、`f_profile`(低頭側臉,無五官)、`f_reach`(一手伸出、一手撫胸,閉眼)、
`f_eye`(臉部特寫,睜開一隻眼)、`boy_bust`、`man_bust`、`cat_bust`、`cat_paws`。全部是胸像或特寫,長邊 1254–1449 px。

下面是做完第四版之後,**實際碰到「沒有這張圖所以只能繞過去」的地方**,按對成片幫助多大排序。
每一項寫明構圖、用在哪一個時刻、現在是怎麼繞過去的。共同的規格放在最後。

## 規格建議(按重要程度)

1. **解析度**:會做特寫的圖(眼睛、手)長邊 3000 px 以上;其餘胸像 2000 px 以上。現在的圖在 4K 滿版特寫時是原圖的 3.5–5.5 倍,
   全靠載入時把墨版描成路徑;原圖更大,邊緣的細節(髮絲、睫毛)才留得住。
2. **嚴格三墨**:只用橙、米白、近黑三種平塗色,不要漸變、不要第四種顏色(`f_reach` 裡有一種鏽色,現在是併入黑色處理的)、
   不要半透明的光暈。墨與墨之間的邊界保留正常的抗鋸齒即可。
3. **透明底要乾淨**:主體的 alpha 請是 255(現有的圖是 253 / 254),主體以外請是 0(現有的圖有 alpha 小於 16 的殘點,帶著紅色和白色)。
4. **不要裁切,四邊留白**:頭頂(花飾、耳尖)和左右至少留 5 %;胸像的底邊請切在一條水平直線上,或者乾脆畫到畫面外再整張給我。
   被裁切的邊在片中只能貼著畫面邊或面板邊使用,非常限制構圖。
5. **同一組圖互相配準**:下巴、花飾、領口落在相同的座標上,大小一致(現在 `cat_bust` 與 `f_bust` 幾乎重合,可以直接硬切,這點非常好用;
   `boy_bust`、`man_bust` 要縮放 0.89 / 0.873 再位移才對得上)。
6. **如果方便,每種墨一個圖層**(三張同尺寸的 PNG,或一個分層檔):可以省掉載入時的分色,錯版(套不準)的效果也會更乾淨。
7. **臉**:無臉的圖請保持無臉的畫法一致;有五官的圖,睜眼版和閉眼版最好是同一張圖的兩個狀態(其餘部分逐像素相同)。
